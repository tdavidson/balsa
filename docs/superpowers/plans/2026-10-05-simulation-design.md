# Bounded operating studies: design review

The dimensional forecast model already supports dimension-aware formulas. Operating studies should keep the existing scalar graph as the bounded execution representation, with explicit entity/cohort membership attached to nodes and output allocations in the study. This avoids introducing a second formula language or accounting engine. Cross-entity edges and lag edges represent interactions within a world; independently sampled worlds do not interact.

The first simulation budget is 16–64 paths per case, at most three cases, eight uncertain inputs, 12 entities, 80 graph nodes and 24 months. Every valid path must run through the existing journal engine. Failed paths remain in the denominator and prevent unconditional distribution claims. Saved studies have a 16 MB cap. Sampling is seeded and versioned; explicit uniform ranges and shared rank groups describe user assumptions, not empirically estimated probabilities. Positive/inverse rank coupling is deliberately limited and must not be described as a fitted correlation matrix.

Entity memberships are disjoint for cash outputs; shared outputs are explicitly unallocated. Shared constraints, cannibalization, and delayed responses use normal graph dependencies. Structural alternatives are separately preserved complete graphs, with no inferred weights. Output quantiles use ordered exact minor units; financial valuation uses fixed decimal monthly discounting, a stated cash-flow basis and explicit terminal multiple. Price matching returns sampled combinations, not a uniquely inferred market probability distribution.

Review findings: retain exact inputs and source lineage; forbid automatic financial application; preserve exceptions and sample exclusions; separate per-case results; show convergence as a diagnostic rather than validation; label sensitivity as association. New graph structures require a new study snapshot. Analytical save is separate from scenario approval and never posts journals.
